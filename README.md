#  Morphku - Aplikasi Breeding Reptil

Morphku adalah aplikasi untuk mencatat, mengelola, dan memantau breeding reptil.
Dibuat untuk breeder agar tidak lagi mencatat di kertas / excel yang gampang hilang.

##  Fitur Utama

- **Login Google** - Aman, tanpa ribet bikin akun baru
- **Kelola Koleksi** - Tambah, edit, hapus data reptil (morph, jenis kelamin, tanggal lahir)
- **Breeding Tracker** - Catat pairing, tanggal kawin, tanggal bertelur / melahirkan
- **Kalkulator Morph** - Hitung prediksi an
